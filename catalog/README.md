1. **别手改**：这些是"签过字"的凭据，改一个数字就与快照指纹对不上，工具会判定清单过期。
2. **别当临时文件删**：删了就得从阶段一重新走一遍（提元素 → 你确认 → 找资产 → 再确认）。
