# catalog/ · 阶段一的使用物（**本包为空，等你走完阶段一**）

这个目录里会由工具**自动**生成三份东西，都不需要你手写：

| 文件 | 谁写 | 里面是什么 |
|---|---|---|
| `elements.json` | `confirm_elements` | **你确认过**的元素清单（按大类填的表 + 两个场景项：地图大小 / 地图对应时间） |
| `asset_list.json` | `confirm_assets` | 使用给你的资产清单（逐个验证过存在性 + 实测包围盒尺寸；没有资产的登记成白膜占位） |
| `library_snapshot.json` | `confirm_assets` | 资产库指纹快照 —— 用来判断"这张清单还是不是签字时的那张" |
| `archive/` | 工具 | 每次重签前的旧版留档 |

## 请守两条

1. **别手改**：这些是"签过字"的凭据，改一个数字就与快照指纹对不上，工具会判定清单过期。
2. **别当临时文件删**：删了就得从阶段一重新走一遍（提元素 → 你确认 → 找资产 → 再确认）。

> 想从零开始重试阶段一：让 AI 重新调 `confirm_elements`（会覆盖，旧版自动留档到 `archive/`）。
