# 交付说明 · 用之前先读这一页

> 这份给**使用者**看（准备什么、怎么用、现在做不到什么）。
> 装机命令与各客户端配置见 `SETUP.md`；给 AI 的规则见 `AGENTS.md`；各阶段口径见 `docs/`。

## 一句话

你把**一张参考图**交给 AI，它把街景规划成**一份可核对的平面布局**（每个物体一行：中心坐标 + 占地 + 朝向），再在**你自己指定的 UE 关卡**里按这份布局搭建；之后要改，**只改你指的那几处**，不会把整个场景推倒重来。

## 一、你要准备四样

| # | 东西 | 为什么 |
|---|---|---|
| 1 | Unreal Engine + **官方 Unreal MCP 插件** | 本工具是"编排层"，改关卡 / 摆 Actor 全经官方那侧；官方固定吃 `127.0.0.1:8000`。⚠ 没开 UE，只有离线工具能用 |
| 2 | **一个关卡**（新建或已有的） | ⚠ 官方工具**没有"新建关卡"**（实测只有 `load_level`）—— 新图必须**你自己**在 UE 里建好并打开 |
| 3 | 一张**参考图** | 一张图 + 一句需求就够 |
| 4 | 装好**资产包** | 名字对不上的资产不会被顶替，会先登记成**白膜占位**（灰色方块）；补齐后可替换 |

## 二、怎么装（约 2 分钟）

1. 解压到一个**路径里没有空格**的目录（Trae 的配置不允许含空格）；
2. 在该目录里跑：`.\setup.ps1` —— 它会建环境、装依赖、**跑自检**（绿了才谈得上连）、并写好各家客户端的配置；
3. 按你的客户端做**最后一次动作**：

   | 客户端 | 你要做的 |
   |---|---|
   | 豆包 PC | **重启客户端**（它的 MCP 在启动时读配置） |
   | Trae | 设置 → MCP → 打开「**启用项目级 MCP**」 |
   | Cursor | 重载窗口 |
   | DSH | 把 `connect-config.json` 里「DSH（stdio）」那段填进 MCP 设置 → 重启会话 |

4. 让 AI 调一次 `get_plan()`：能返回状态就说明通了（连上应有 **13 个工具**）。

## 三、用起来是什么样：AI 干重活，你只点 4 次头

| # | 谁 | 做什么 | 停在哪 |
|---|---|---|---|
| 1 | 你 | 发参考图 + 一句需求 | — |
| 2 | AI | 读图 → 列出"需要哪些元素"（含数量和场景信息） | **等你确认这张表** |
| 3 | AI | 按名字找资产（找不到如实报缺）→ 出资产清单 | **等你确认清单** |
| 4 | AI | 规划每件东西的位置 → **自己画一张平面图**递给你 | **等你点头** |
| 5 | AI | 翻成 UE 指令 → **先演练**给你看 → 落到关卡里 | — |
| 6 | 你 | **自己在 UE 里按保存** | — |

改动也是一样的路子：你说"第 3 栋往左挪 5 m" → 它只改那一行 → **只重画改动的那几行** → 你再看一眼 → 它**只重摆那几个**（实测：改 5 行时全场景只动了 5 个、31 次调用；全量重摆要 383 次）。

## 四、三条必须先知道的规矩

1. **它绝不替你保存**。摆完只存在 UE 内存里（标题栏会出现未保存标记）—— 存不存、什么时候存，**由你决定**。这是刻意的：不替用户动他的工程。
2. **它不猜资产**。名字对不上就是"没找到"，它会明确告诉你缺什么，并请你给出资产的【路径 + 名字】。缺的东西先登记成**白膜占位**，不会拿别的资产顶替。
3. **确认靠那张图**。你读不懂坐标没关系 —— AI 会把图**做成能点开的卡片**递给你，你只判断"摆得对不对"。**你不点头，它就进不了下一步**（这条闸门写在代码里，不靠 AI 自觉；换任何客户端都绕不过）。

## 六、出问题先看这三处

1. 工具报**没有正文**的错（只有一句 `Error executing tool …`）→ 完整栈在宿主的
   `%APPDATA%\dsh-desktop\logs\harness.log`，搜工具名即可定位；
2. 连不上 UE → 确认 UE 开着、官方 MCP 插件启用、`127.0.0.1:8000` 在监听；
3. 装不上 / 起不来 → 先跑 `& .\.venv\Scripts\python.exe tests\preflight.py`，按红字逐条修。

## 七、你的数据在哪（别手改）

| 路径 | 里面是什么 |
|---|---|
| `catalog/` | 阶段一**签过字**的交付物：元素表、资产清单、资产库指纹快照 |
| `views/plan_v1.json` | **当前这一版**平面放置表（闸门认的就是它） |
| `views/build_orders_v1.json` | 翻给 UE 的搭建指令表（厘米） |
| `views/build_state_v1.json` | **搭建台账**：关卡里现在到底摆了什么 |
| `views/acceptance.json` | 验收台账：谁 / 何时 / 哪一版几何确认过 |
| `views/*.svg` | 给你看的确认图（由 AI 画） |
| `views/archive/` | 历史留档（旧版数据与旧图，只增不减） |

⚠ **这些都是纯文本/JSON，都别手动改** —— 改一个数就与几何指纹对不上，等于把已经确认过的那一版作废，必须重新给你看图、重新确认。
