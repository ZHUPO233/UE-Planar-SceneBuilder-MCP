## 四、调用关系（谁调谁）

```
Agent（DSH）
   │  tools/call
   ▼
main.py 的 19 个 @mcp.tool()          ← 每个工具的第一件事，往往是过闸
   │
   ├──► planning/plan.py（离线）      plan 模型 / 指纹 / 越界 / 验收台账 / CLI
   ├──► 我们自己的 JSON（views/ catalog/ config/）
   └──► call_official(ctx, 工具名, 参数, toolset=…)
             │
             ▼
        官方 Unreal MCP（HTTP 127.0.0.1:8000/mcp，52 个工具集）
             │
             ▼
        UE 编辑器（关卡 / Actor / 材质 / 环境）
```

**三条纪律**（`实测`）：① **编排层自己完全不碰 UE**，一切经官方；② **不许裸调官方**绕过闸；③ **绝不存盘**（不调任何 save 类官方工具）。
