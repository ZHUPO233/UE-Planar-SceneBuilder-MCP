# 阶段五 · 表面材质

> 给**白膜**贴表面材质（车行道柏油 / 人行道混凝土 / 草坪 / 灌木植被…）—— 让场景不再是灰白模。
> 实现 = `apply_surfaces()`；材质表在 `config/surface_materials.json`（**改它不用改代码、不用重启**）。

## 一、原口径 vs 实际落地

**原口径**设想的是**在 DCC 端**批量加载 → 按层实例化 → 单位与轴向适配。

⚠ 实际落地的是 **UE 直连路线**：`apply_surfaces()` 给白膜贴表面材质 —— 贴的是**组件级 `overrideMaterials`**，
**不改资产**（改资产会把 `/Engine/BasicShapes/Cube` 这种引擎自带网格一起改掉、所有实例跟着变 —— 实测确认过）。
原文里的"批量加载 / 单位与轴向适配"，在"本来就在 UE 里 spawn"这条链上**没有对象**了。

## 二、规则（都写在代码里）

- **只贴白膜行**；资产行（house / tree / shrub…）**自带材质**，本工具不碰。
- **表里没填路径就不贴** —— `materials` 为空 = 一个元素都不贴；工具会**明说**，不假装贴了。
- 逐个验路径：有一条 `exists()` 不过就**整批拒收**（与阶段一"一条不过就一个都不落"同一条纪律）。
- **绝不存盘** —— 贴完你在 UE 里看，存不存由你定。

## 三、口径出处

- 工具描述：`main.py` 的 `apply_surfaces()`
- 材质表：`config/surface_materials.json`（键 = `element_key`，值 = 材质**包路径**）
- 相关闸门：`docs/全流程-闸门地图.md` 的 **G10 · 材质路径**
- 云量 / 云密度这类**材质级**参数属阶段六：见 `docs/阶段六-环境搭建.md` 的「甲 · 五」
