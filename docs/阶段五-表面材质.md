# 阶段五 · 表面材质

> 给**白膜**贴表面材质（车行道柏油 / 人行道混凝土 / 草坪 / 灌木植被…）—— 让场景不再是灰白模。
> 实现 = **`apply_surfaces()`（第 1 步：贴已有的）** + **`create_surfaces()`（第 0 步：把缺的建出来）**；
> 两张表都在 `config/surface_materials.json`（`materials` / `create` 两段，**改它不用改代码、不用重启**）。

## 〇、第 0 步：缺的材质先建出来（`create_surfaces`，2026-10-04 加 · ⚠ **尚未实测**）

**为什么有这一步**：`apply_surfaces()` 只能贴**已存在**的材质 —— 现场那 6 个 `/Game/UEMCP/Materials/M_*`
在工程里根本不存在 → 逐个 `exists()` 不过 → **整批拒收、一个都不贴**（结果就是白模）。
缺的那一半（**建材质**）官方本来就有工具（`MaterialTools`：`create_material` / `add_expression` /
`connect_to_output` / `recompile`，2026-10-04 实测 `describe_toolset` 确认）—— **缺的是编排**。

**它做什么**：读 `create` 段 → **整批校验**（配置有任意一条不合法 ⇒ 一个都不建）→ 逐个 `exists()`
（**已存在 = 跳过**，幂等）→ `create_material` + 每个参数 `add_expression` + `set_properties` +
`connect_to_output(MP_<键名>)` → `_flags`（`twoSided` / `blendMode`）→ `recompile` →
**读回核对**（`list_parameters` 参数在不在 + `get_property_input` 输出接上没）→ 落台账
`views/surface_materials_v1.json`（**我们建了什么**，给回滚/追查用）。

**三条纪律**（与阶段五其余部分一致）：**绝不存盘**（新建的材质只在内存里 —— 报文里明说"记得 Ctrl+S"）·
**绝不覆盖**已有材质（`exists()` 为真一律跳过）· **只建"空材质 + 参数节点"**（要贴图 / 混合 / 蒙版的
材质图仍得你在 UE 材质编辑器里做，再把路径填进 `materials` 段）。

⚠ **尚未实测的两处**：`parameterName` / `defaultValue` 这两个**表达式属性名**是按官方常规命名写的
（`main.py` 顶部 `MAT_PARAM_*` 常量）；真跑报错时官方原文会带出来，改那两个常量即可。第一次真跑请先
`dry_run=true`。`_flags`（`twoSided` / `blendMode`）本版**只写不读回**，报文里会如实点名。

## 一、原口径 vs 实际落地

**原口径**设想的是**在 DCC 端**批量加载 → 按层实例化 → 单位与轴向适配。

⚠ 实际落地的是 **UE 直连路线**：`apply_surfaces()` 给白膜贴表面材质 —— 贴的是**组件级 `overrideMaterials`**，
**不改资产**（改资产会把 `/Engine/BasicShapes/Cube` 这种引擎自带网格一起改掉、所有实例跟着变 —— 实测确认过）。
原文里的"批量加载 / 单位与轴向适配"，在"本来就在 UE 里 spawn"这条链上**没有对象**了。

## 二、规则（都写在代码里）

- **只贴白膜行**；资产行（house / tree / shrub…）**自带材质**，本工具不碰。
- **表里没填路径就不贴** —— `materials` 为空 = 一个元素都不贴；工具会**明说**，不假装贴了。
- 逐个验路径：有一条 `exists()` 不过就**整批拒收**（与阶段一"一条不过就一个都不落"同一条纪律）。
- **绝不存盘** —— 贴完你在 UE 里看，存不存由你定。

## 三、口径出处

- 工具描述：`main.py` 的 `apply_surfaces()`
- 材质表：`config/surface_materials.json`（键 = `element_key`，值 = 材质**包路径**）
- 相关闸门：**闸门总表**（开发向文档，不随包发布） 的 **G10 · 材质路径**
- 云量 / 云密度这类**材质级**参数属阶段六：见 `docs/阶段六-环境搭建.md` 的「甲 · 五」
